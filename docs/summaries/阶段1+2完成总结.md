## 🔑 核心架构

### 完整的数据流：

```
1. 用户发送消息
   ↓
2. 后端意图识别 + RAG 检索
   ↓
3. 生成 A2UI 消息序列：
   - beginRendering (root: "main_component")
   - surfaceUpdate (组件使用 path 绑定)
   - dataModelUpdate (设置初始数据)
   ↓
4. WebSocket 流式传输到前端
   ↓
5. 前端 A2UIRenderer 处理消息：
   - 创建 surface
   - 渲染组件（path 绑定）
   - 更新数据模型
   ↓
6. 组件自动响应式更新
   ↓
7. 后续 dataModelUpdate 可实时更新组件
```

### 技术亮点：

1. **响应式数据绑定**
   - 组件使用 `path` 绑定到数据模型
   - 数据更新时组件自动重新渲染
   - 无需手动刷新或重新创建组件

2. **会话状态管理**
   - 每个会话维护独立的数据模型
   - 支持多 surface 状态隔离
   - 支持增量更新和批量合并

3. **WebSocket 实时通信**
   - 双向通信：客户端 ↔ 服务器
   - 自动重连机制（最多5次）
   - 消息类型路由：text, a2ui, action, error

4. **流式消息处理**
   - 后端流式发送 A2UI 消息
   - 前端逐条接收和处理
   - 支持大型 A2UI 响应
