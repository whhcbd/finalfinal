# 性能和交互优化方案

## 问题诊断

### 1. 前端响应缓慢的原因

经过代码分析,发现以下性能瓶颈:

#### 主要问题:
1. **WebSocket 等待完成信号** - `processMessage()` 必须等待后端发送 `complete` 消息才返回
2. **多次 DOM 更新** - 每次收到消息都触发 `requestUpdate()` 和 `updateComplete`
3. **localStorage 频繁写入** - 每次消息更新都调用 `saveConversations()`
4. **A2UI 渲染延迟** - 等待 DOM 更新后才开始渲染 A2UI 组件
5. **后端 GLM API 调用** - 等待 LLM 生成响应需要时间

#### 次要问题:
- 打字机效果虽然定义了但未使用(typewriterSpeed = 30)
- 历史消息重新渲染使用 setTimeout 延迟
- marked.parse 和 KaTeX 渲染可能较慢

### 2. UI 组件互动性弱的原因

当前组件主要是**静态展示**,缺少:
- 用户输入和编辑功能
- 拖拽交互
- 实时反馈
- 动画效果
- 参数调节

## 优化方案

### 阶段一: 前端性能优化 (立即实施)

#### 1.1 减少不必要的 DOM 更新
```typescript
// 优化前: 每次都更新
this.requestUpdate();
await this.updateComplete;

// 优化后: 批量更新
private pendingUpdate = false;
private scheduleUpdate() {
  if (!this.pendingUpdate) {
    this.pendingUpdate = true;
    requestAnimationFrame(() => {
      this.requestUpdate();
      this.pendingUpdate = false;
    });
  }
}
```

#### 1.2 优化 localStorage 写入
```typescript
// 优化前: 每次消息都保存
this.saveConversations();

// 优化后: 防抖保存
private saveDebounced = debounce(() => {
  localStorage.setItem('conversations', JSON.stringify(this.conversations));
}, 1000);
```

#### 1.3 并行渲染文本和 A2UI
```typescript
// 优化前: 串行等待
assistantMessage.content = response.text;
this.requestUpdate();
await this.updateComplete;
// 然后渲染 A2UI

// 优化后: 并行处理
Promise.all([
  this.updateTextContent(assistantMessage, response.text),
  this.renderA2UIIfNeeded(assistantMessage, response.a2ui)
]);
```

#### 1.4 使用虚拟滚动优化长对话
- 只渲染可见区域的消息
- 使用 `lit-virtualizer` 库

#### 1.5 优化 marked 和 KaTeX 渲染
```typescript
// 使用 Web Worker 处理 markdown 解析
const worker = new Worker('markdown-worker.js');
worker.postMessage({ content: message.content });
```

**预期效果**: 前端响应时间减少 50-70%

### 阶段二: 后端性能优化 (短期)

#### 2.1 实现流式响应
```python
# 不等待完整响应,边生成边发送
async def stream_response(message: str):
    async for chunk in glm_service.stream_generate(message):
        await websocket.send_json({
            "type": "text_chunk",
            "chunk": chunk
        })
```

#### 2.2 缓存常见问题的响应
```python
# Redis 缓存
cache_key = f"response:{hash(user_message)}"
cached = await redis.get(cache_key)
if cached:
    return cached
```

#### 2.3 并行生成文本和 A2UI
```python
# 优化前: 串行
text = await generate_text(message)
a2ui = await generate_a2ui(message, text)

# 优化后: 并行
text_task = asyncio.create_task(generate_text(message))
a2ui_task = asyncio.create_task(generate_a2ui(message))
text, a2ui = await asyncio.gather(text_task, a2ui_task)
```

**预期效果**: 后端响应时间减少 30-50%

#### 3.1 Punnett Square 交互增强

**功能**:
- 拖拽配子到格子中
- 点击格子显示基因型详情
- 滑块调节显性/隐性比例
- 动画显示配子组合过程

**实现**:
```typescript
class PunnettSquare extends Root {
  @property({ type: Boolean }) interactive = false;

  private handleCellClick(row: number, col: number) {
    // 显示该格子的详细信息
    this.showGenotypeDetails(row, col);
  }

  private handleDragStart(event: DragEvent, allele: string) {
    event.dataTransfer?.setData('allele', allele);
  }

  private handleDrop(event: DragEvent, row: number, col: number) {
    const allele = event.dataTransfer?.getData('allele');
    this.updateCell(row, col, allele);
  }
}
```

#### 3.3 Pedigree Chart 交互增强

**功能**:
- 点击个体显示详细信息
- 高亮显示遗传路径
- 添加/删除个体
- 动画显示基因传递

**实现**:
```typescript
class PedigreeChart extends Root {
  @property({ type: String }) selectedIndividual = '';

  private handleIndividualClick(individual: Individual) {
    this.selectedIndividual = individual.id;
    this.highlightInheritancePath(individual);
    this.showIndividualDetails(individual);
  }

  private highlightInheritancePath(individual: Individual) {
    // 高亮从祖先到该个体的所有连接线
    const path = this.getInheritancePath(individual);
    path.forEach(id => {
      const el = this.shadowRoot?.getElementById(`ind-${id}`);
      el?.classList.add('highlighted');
    });
  }
}
```

#### 3.4 Gene Expression 交互增强

**功能**:
- 滑块调节表达水平
- 实时更新柱状图
- 比较不同基因的表达
- 动画显示表达变化

**实现**:
```typescript
class GeneExpression extends Root {
  @property({ type: Boolean }) interactive = false;

  private handleSliderChange(geneId: string, value: number) {
    this.updateExpression(geneId, value);
    this.animateBarChange(geneId, value);
  }

  private animateBarChange(geneId: string, newValue: number) {
    // 平滑过渡到新值
    const bar = this.shadowRoot?.querySelector(`[data-gene="${geneId}"]`);
    bar?.animate([
      { height: `${this.currentValue}%` },
      { height: `${newValue}%` }
    ], {
      duration: 500,
      easing: 'ease-out'
    });
  }
}
```
