## 🎨 动画库设计

### 核心特性

#### 1. 性能优化
```css
/* 硬件加速 */
.hw-accelerate {
  transform: translateZ(0);
  will-change: transform;
}

/* 无障碍支持 */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

#### 2. 标准脉冲动画
```css
@keyframes pulse {
  0%, 100% {
    box-shadow: 0 0 0 0 rgba(59, 130, 246, 0.7);
    transform: scale(1);
  }
  50% {
    box-shadow: 0 0 0 10px rgba(59, 130, 246, 0);
    transform: scale(1.05);
  }
}

.pulse {
  animation: pulse 1.5s ease-in-out infinite;
}
```

#### 3. 组件特定动画
```css
/* Punnett Square - 配子合并 */
@keyframes gamete-merge {
  0% { transform: scale(1) translateX(0) translateY(0); }
  50% { transform: scale(0.5) translateX(20px) translateY(20px); }
  100% { transform: scale(1) translateX(40px) translateY(40px); }
}

/* DNA Structure - 双螺旋旋转 */
@keyframes helix-rotate {
  from { transform: rotateY(0deg); }
  to { transform: rotateY(360deg); }
}

/* Pedigree Chart - 基因流动 */
@keyframes gene-flow {
  0% { stroke-dashoffset: 1000; opacity: 0.3; }
  100% { stroke-dashoffset: 0; opacity: 1; }
}

/* Gene Expression - 柱状图增长 */
@keyframes bar-grow {
  from { width: 0; opacity: 0; }
  to { opacity: 1; }
}

/* Crossover Map - 交叉闪烁 */
@keyframes crossover-flash {
  0%, 100% { opacity: 0; }
  10%, 30%, 50%, 70%, 90% { opacity: 1; }
  20%, 40%, 60%, 80% { opacity: 0.3; }
}
```

## 💻 技术实现

### 集成方式

所有 6 个组件使用统一的导入模式：

```typescript
import { html, css, unsafeCSS } from 'lit';
import animationStyles from '../../styles/animations.css?inline';

static styles = [
  ...Root.styles,
  css`${unsafeCSS(animationStyles)}`,
  css`
    /* 组件特定样式 */
  `
];
```

### Vite 配置

使用 `?inline` 后缀导入 CSS 文件为字符串，然后通过 `unsafeCSS()` 注入到 Lit 组件的 Shadow DOM 中。

## 🔄 使用示例

### 在组件中使用动画

#### 1. 添加 CSS 类
```typescript
render() {
  return html`
    <div class="cell ${this.isSelected ? 'pulse' : ''}">
      Cell content
    </div>
  `;
}
```

#### 2. 动态触发动画
```typescript
private handleClick() {
  const element = this.shadowRoot?.querySelector('.target');
  element?.classList.add('pop');
  setTimeout(() => element?.classList.remove('pop'), 300);
}
```

#### 3. 组合多个动画
```typescript
render() {
  return html`
    <div class="modal fade-in scale-in">
      Modal content
    </div>
  `;
}
```

## 💡 设计亮点

### 1. 统一的动画语言
所有组件共享相同的动画风格和时长，提供一致的用户体验。

### 2. 性能优先
- 使用 CSS 动画而非 JavaScript
- GPU 加速（transform, opacity）
- 避免触发 reflow 的属性

### 3. 无障碍友好
自动检测 `prefers-reduced-motion` 并禁用动画，照顾运动敏感用户。

### 4. 易于扩展
新组件只需导入动画库，即可使用所有动画效果。

### 5. 组件特定动画
为每个组件设计专属动画，增强教学表现力。
