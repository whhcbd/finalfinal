#### 复制动画逻辑
```typescript
private async startReplication() {
  this.replicationMode = true;
  this.replicationProgress = 0;

  const sequence = this.unwrapValue(this.sequence, 'string');
  const totalBases = sequence.length;
  const stepDuration = 2000 / totalBases; // 2秒完成

  for (let i = 0; i <= totalBases; i++) {
    await new Promise(resolve => setTimeout(resolve, stepDuration));
    this.replicationProgress = (i / totalBases) * 100;

    // 为当前碱基添加脉冲动画
    if (i < totalBases) {
      const bases = this.shadowRoot?.querySelectorAll('.base');
      bases[i].classList.add('replicating');
      setTimeout(() => {
        bases[i].classList.remove('replicating');
        bases[i].classList.add('newly-synthesized');
      }, 300);
    }
  }

  this.replicationMode = false;
}
```

## 🔄 消息流程

### 碱基点击流程
```
用户点击碱基
  ↓
handleBaseClick() 触发
  ↓
更新 selectedBase 状态
  ↓
显示配对详情弹窗
  ↓
渲染氢键（2个或3个）
  ↓
dispatch a2ui-action 事件
  ↓
WebSocket 发送到后端
  ↓
_handle_base_click() 处理
  ↓
返回 dataModelUpdate 消息
```

### DNA 复制流程
```
用户点击"开始复制"
  ↓
startReplication() 触发
  ↓
设置 replicationMode = true
  ↓
dispatch start_replication action
  ↓
循环遍历每个碱基
  ↓
添加 .replicating 类（脉冲动画）
  ↓
300ms 后移除 .replicating
  ↓
添加 .newly-synthesized 类（淡入动画）
  ↓
更新进度条（0-100%）
  ↓
复制完成，设置 replicationMode = false
  ↓
dispatch replication_complete action
```
