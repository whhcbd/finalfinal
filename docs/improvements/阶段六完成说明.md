#### 筛选逻辑
```typescript
private getFilteredData(data: PhenotypeData[]): PhenotypeData[] {
  if (this.selectedFilters.length === 0) {
    return data; // 无筛选，显示全部
  }
  return data.filter(item => this.selectedFilters.includes(item.phenotype));
}
```

## 🔄 消息流程

### 柱状图点击流程
```
用户点击柱状图
  ↓
handleBarClick() 触发
  ↓
更新 selectedPhenotype 状态
  ↓
显示详情弹窗
  ↓
dispatch a2ui-action 事件
  ↓
WebSocket 发送到后端
  ↓
_handle_phenotype_bar_click() 处理
  ↓
返回 dataModelUpdate 消息
```

### 筛选器变化流程
```
用户切换复选框
  ↓
handleFilterChange() 触发
  ↓
更新 selectedFilters 数组
  ↓
getFilteredData() 重新计算数据
  ↓
柱状图宽度重新计算（.animating 类）
  ↓
统计数据更新
  ↓
dispatch a2ui-action 事件
  ↓
后端记录筛选状态
```
